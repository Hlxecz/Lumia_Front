## 2-2. Class Diagram Description

###  패키지별 상세 설명 문서
Lumia 시스템의 각 패키지 설계 및 구성 정보는 아래의 개별 문서에서 확인할 수 있습니다.

*  **[Full Project Class Diagram Description](./class_descriptions/PROJECT_CLASS_DIAGRAM_DESCRIPTION.md)**: 백엔드 전체 프로젝트 클래스 구성 요약
*  **[Root Package](./class_descriptions/ROOT_CLASS_DIAGRAM_DESCRIPTION.md)**: 애플리케이션 시작점 및 데이터 초기화 설계
*  **[Controller Package](./class_descriptions/CONTROLLER_CLASS_DIAGRAM_DESCRIPTION.md)**: 사용자 요청 및 API 통제 계층 설계
*  **[Service Package](./class_descriptions/SERVICE_CLASS_DIAGRAM_DESCRIPTION.md)**: 비즈니스 로직 및 외부 API 연동 계층 설계
*  **[Repository Package](./class_descriptions/REPOSITORY_CLASS_DIAGRAM_DESCRIPTION.md)**: 데이터베이스 접근 및 쿼리 메서드 설계
*  **[Entity Package](./class_descriptions/ENTITY_CLASS_DIAGRAM_DESCRIPTION.md)**: DB 테이블 매핑 및 도메인 엔티티 설계
*  **[DTO Package](./class_descriptions/DTO_CLASS_DIAGRAM_DESCRIPTION.md)**: API 입출력 스펙 및 데이터 이동 객체 설계
*  **[Config Package](./class_descriptions/CONFIG_CLASS_DIAGRAM_DESCRIPTION.md)**: Spring Security, CORS, 외부 API 클라이언트 설정 설계
*  **[Security Package](./class_descriptions/SECURITY_CLASS_DIAGRAM_DESCRIPTION.md)**: JWT 생성/인증 및 보안 필터 설계
*  **[Exception Package](./class_descriptions/EXCEPTION_CLASS_DIAGRAM_DESCRIPTION.md)**: 예외 감지 및 비즈니스 예외 코드 정의 설계
