# 6. Glossary

[⬅️ Back to Contents](./Conceptualization.md)

---

본 문서에서 사용되는 주요 기술 용어 및 서비스 용어에 대한 정의입니다.

| Term                     | Definition                                                                                                                                           |
| :----------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------- |
| **JWT (JSON Web Token)** | 선택된 클라이언트와 서버 간에 정보를 안전하게 전송하기 위한 개방형 표준(RFC 7519)으로, 본 프로젝트에서는 사용자의 인증 및 권한 관리를 위해 사용된다. |
| **Spring Boot**          | 자바 기반의 오픈 소스 프레임워크로, REST API 서버 구축 및 비즈니스 로직 처리를 담당하는 백엔드 핵심 기술이다.                                        |
| **OpenAI API**           | 인공지능 모델(GPT)을 활용할 수 있도록 제공되는 인터페이스로, 사용자의 답변을 분석하고 공감 메시지를 생성하는 데 사용된다.                            |
| **FastAPI**              | 파이썬 기반의 고성능 웹 프레임워크로, 본 프로젝트에서는 텍스트 필터링 및 검열 기능을 수행하는 보조 서버 구축에 활용된다.                             |
| **Transaction**          | 데이터베이스의 상태를 변화시키는 하나의 논리적 작업 단위로, 답변 제출과 보상 지급의 원자성(Atomicity)을 보장하기 위해 사용된다.                      |
| **Gamification**         | 게임이 아닌 분야에 게임의 메커니즘을 접목하는 것으로, 캐릭터 성장 및 코인 시스템을 통해 사용자의 지속적인 참여를 유도한다.                           |
| **Reflect (회고)**       | 자신의 감정과 경험을 되돌아보는 행위로, 루미아 서비스의 핵심 사용자 활동을 의미한다.                                                                 |
| **Seed (씨앗)**          | 커뮤니티에서 게시글에 대한 긍정적인 반응이나 공감을 표시할 때 사용하는 상호작용 버튼 및 재화 단위를 의미한다.                                        |
