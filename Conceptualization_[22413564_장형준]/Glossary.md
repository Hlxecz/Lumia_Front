# 6. Glossary

[⬅️ Back to Contents](./Conceptualization.md)

---

| 용어 | 설명 |
| :--- | :--- |
| **JWT (JSON Web Token)** | 당사자 간에 정보를 JSON 개체로 안전하게 전송하기 위한 개방형 표준으로, 본 프로젝트에서는 사용자 인증 및 세션 관리를 위해 사용한다. |
| **Access Token** | 사용자가 인증되었음을 증명하는 단기 토큰으로, API 요청 시 권한 확인을 위해 사용된다. |
| **Refresh Token** | Access Token이 만료되었을 때 새로운 토큰을 재발급받기 위한 장기 토큰으로, 보안성을 유지하면서 사용자 편의를 제공한다. |
| **Transaction (트랜잭션)** | 데이터베이스의 상태를 변화시키는 하나의 논리적 작업 단위이다. 답변 저장과 보상 지급을 하나로 묶어 데이터의 일관성을 보장한다. |
| **FastAPI Filter** | 파이썬 기반의 웹 프레임워크인 FastAPI를 활용하여 구축된 외부 서버로, 게시글의 비속어 및 부적절한 콘텐츠를 실시간으로 필터링한다. |
| **Gamification (게이미피케이션)** | 게임이 아닌 분야에 게임의 요소를 접목하는 것으로, 루미아에서는 코인 보상과 캐릭터 성장 시스템을 통해 사용자의 지속적인 참여를 유도한다. |
| **Exception Handling (예외 처리)** | 프로그램 실행 중 발생할 수 있는 오류 상황에 대비하는 기술로, 외부 API 장애 시 시스템의 중단을 방지하고 사용자에게 적절한 안내를 제공한다. |
| **Data Integrity (데이터 무결성)** | 데이터베이스 내의 데이터가 전 과정에서 정확성, 일관성, 유효성을 유지하는 것을 의미한다. |
| **Retention (리텐션)** | 서비스에 한 번 가입하거나 방문한 사용자가 특정 기간이 지난 후에도 다시 돌아오는 비율입니다. |
